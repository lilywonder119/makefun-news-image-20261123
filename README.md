# THE FULL RECORD — Monday 23 November 2026

One-page newspaper front page for Monday 23 November 2026, built around the
day's lead: thousands marching in Lisbon over the cost of living. Thirteen
large numbered cards, a numbered ALSO ON THE DAY list (40 stories in all,
8 regions), a dotted world map with numbered pins, THE DAY IN NUMBERS,
a DATE CHECK box and a HOW SURE WE ARE footer. White paper, navy ink,
old-gold accents.

## Run

    python3 main.py

That copies the finished `entry.png` into the folder named by
`MAKEFUN_OUTPUT_DIR` (default: `out`). The picture itself is drawn by
`compose.py`; `main.py` only carries the finished file across.
